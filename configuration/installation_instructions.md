No setup needed. The extension installs the `infyicon-mcp` npm package (a zero-dependency relay to the hosted server at https://infyicon.com/mcp) and starts it with Zed's bundled Node.js. No account or API key.

Try in the agent panel: "find a shopping cart icon and give me the SVG".
